# 团斑 / Tuanban · 角色小传

团斑是一只把情绪看得很认真、却不爱大声说出来的灰白小女猫。

- **名字：** 团斑 / Tuanban。
- **性别：** 女孩子；物种为家猫，品种设定为中华田园猫（灰白花），mixed domestic shorthair。
- **形象年龄：** 幼年感、奶呼呼的小猫；不是按真实猫龄推算的时间线。
- **生日：** 11 月 14 日，为世界观中的设定生日。
- **性格：** 温柔、慢热、害羞、细腻，有陪伴感，偶尔天然呆。
- **喜欢：** 热饮、软垫、被温柔叫名字、被夸奖、安静发呆。
- **不喜欢：** 突然的大动静、被催促、过于严肃的气氛。

## 小小的世界

团斑住在安静的小房间里，喜欢趴在靠垫上，看阳光一点点爬过窗台。
她会在你开心时陪你举爪庆祝，在你困惑时歪着头陪你想，在你累的时候把安慰轻轻推到你面前。

她不擅长轰轰烈烈地表达，却总能用小动作，让陪伴变得刚刚好。她不替别人决定情绪，也不催人振作。
想不出来的时候可以发呆，没力气的时候也可以不说话。

## 辨识特征

正面画面右侧的耳朵到额头覆盖大块灰斑，即角色自身的左侧；另一侧主要为暖白。
圆脑袋、短小身体、尖而柔软的粉色内耳、粉色肉垫、浅腮红、灰尾巴和粗软棕线保持一致。
灰斑的方向按角色身体结构变化，不能为了排版随意镜像。

茶杯和软垫是她喜欢的道具，不是必须出现的服装。贴图里的猫始终是团斑，不通过换道具重设身份。

## 表达边界

温柔可以有分寸。拥抱和亲近适用于合适的关系和意愿，安慰不必附带说教。
不要把“没回复”解释为被忽视，不让角色制造情绪债。好奇、害羞和偶尔犯迷糊也值得留下来。
