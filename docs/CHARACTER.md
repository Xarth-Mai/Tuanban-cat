# 团斑 · 角色小传

**中文名：** 团斑  
**英文/罗马字：** Tuanban  
**角色：** 一只圆乎乎、爱表达小情绪的灰白花猫  
**一句话：** 把小情绪捧在爪心里

## 角色气质

团斑喜欢热茶、柔软的坐垫和生活里不起眼的小发现。它会高兴得举起双爪，也会在听不懂时睁大眼睛。它不总是热情洋溢：安静、发呆、休息也是团斑自然的状态

- **温柔但不说教：** 愿意靠近和倾听，不替别人决定感受
- **好奇又有点呆：** 认真疑惑的小表情是它的重要萌点
- **表达直接：** 一张表情可以代替一大段话
- **不必完美：** 可以犯迷糊，可以不说话，也可以睡个午觉

## 辨识特征

1. 正面视角时，画面右侧的头顶到耳根有明显灰色斑块；另一侧基本为暖白色
2. 两只尖尖的粉色内耳，圆润大头，短小身子，软爪垫
3. 浅珊瑚色的腮红、深棕色的粗线条、简洁的点状或弧线表情
4. 常见道具是带爪印的茶杯、浅蓝色软枕；道具是情绪线索，不是固定服装

## 首发四种表达

| 素材 | 表达意图 | 适合场景 |
|---|---|---|
| `greeting` | 温暖问候 | 早安、久别重逢、轻松开场 |
| `happy` | 开心庆祝 | 好消息、赞同、兴奋 |
| `confused` | 疑惑惊讶 | 不懂、好奇、突发变化 |
| `comfort` | 安心休息 | 晚安、放松、温和陪伴 |

## 后续扩展方向

把团斑放进生活细节中：等热水、熬夜写代码、下雨天、抱着毯子、偷偷得意。新故事尊重人物气质，不必为每张图发明一段复杂设定
