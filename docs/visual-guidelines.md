# 团斑视觉规范 · v1.0

手绘、圆润、柔软，暖棕粗线配淡彩纸张质感；避免写实毛发、硬边 3D 或高饱和荧光色。

| 指导色 | Hex | 用途 |
| --- | --- | --- |
| 奶油白 | #FCF6EC | 背景和毛色 |
| 耳斑灰 | #B8ADB0 | 耳朵与额头斑块 |
| 腮红粉 | #F7B2A4 | 内耳、脸颊、肉垫 |
| 雾蓝 | #A8C4E8 | 小道具、疑问与点缀 |
| 暖棕 | #614B40 | 粗软轮廓 |
| 蜜糖黄 | #F7C46C | 开心星光 |

色板是扩展创作的近似指导色，不是对每个生成像素的精确约束。画面保持柔和、奶油色系。

## 形体与灰斑

头大、身体短、爪子软，面部以点眼、弧眼和小嘴表达。主灰斑在正面画面右侧，即角色自身左侧，
延伸至同侧耳根；背面按解剖位置对应。不要随机换边、对称复制主灰斑或新增固定配饰。

关键词：soft brown outline / cream, gray, pink, blue accent / cozy, gentle, shy, playful / rounded, plush。
