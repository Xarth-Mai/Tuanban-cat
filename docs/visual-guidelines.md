# 团斑 · 视觉规范

团斑的画面应当柔和、圆润，带一点手绘纸张感。使用暖棕粗线条、奶油色背景与浅淡点缀；避免写实毛发、硬边 3D、高饱和荧光色。

## 色彩

| 指导色 | Hex | 用途 |
| --- | --- | --- |
| 奶油白 | `#FCF6EC` | 背景与毛色 |
| 耳斑灰 | `#B8ADB0` | 耳朵与额头斑块 |
| 腮红粉 | `#F7B2A4` | 内耳、脸颊、肉垫 |
| 雾蓝 | `#A8C4E8` | 道具、疑问与点缀 |
| 暖棕 | `#614B40` | 柔软的轮廓 |
| 蜜糖黄 | `#F7C46C` | 开心的星光 |

色板为创作方向，不要求逐像素匹配。

## 形象辨识

团斑有圆脑袋、短小的身体、柔软的爪子和灰色尾巴，眼睛与嘴巴以简单的弧线、点和小表情表达情绪。

**主灰斑位于正面画面的右侧，也就是团斑自身的左侧**，从额头延伸到同侧耳根。背面与侧面应遵循同一身体方向；不能为了排版直接镜像或对称复制灰斑。

可以使用杯子、软垫、星光、爱心、蒸汽等简洁道具，但不新增固定配饰。
