# 团斑视觉规范 · v0.1

## 核心风格

手绘、圆润、柔软，像用棕色粗铅笔和淡彩画出的简单小猫。看起来亲近、无攻击性，小屏幕也能一眼看出当前情绪

## 建议色板

| 名称 | Hex | 用途 |
|---|---|---|
| 奶油白 | `#FCF6EC` | 背景与主体亮部 |
| 暖棕线 | `#614B40` | 脸部与轮廓线 |
| 耳斑灰 | `#B8ADB0` | 头顶灰斑 |
| 腮红粉 | `#F7B2A4` | 耳朵、脸颊、爪垫 |
| 雾蓝 | `#A8C4E8` | 疑问符号、软枕和点缀 |
| 蜜糖黄 | `#F7C46C` | 开心、惊喜的光线 |

这些是**扩展创作的近似指导色**，不是从原始图层读取的精确源色值

## 固定辨识点

正面：画面右上半个额头与耳根的灰色花纹是最重要的识别点；左侧保持暖白。面部中心简洁，嘴和眼睛可夸张变形，浅粉腮红常在。侧面、背面可按结构翻转对应花纹，保持逻辑一致

## 表情图导出

- 文件：独立、正方形 `.png`
- 尺寸：严格 `192 × 192` 像素
- 色彩：8-bit RGB，不含 Alpha、透明信息、调色板或动画帧
- 背景：不透明暖奶油白，避免聊天软件自动填白导致边缘失真
- 体积：单张不大于 40 KiB；优化文件大小不以可辨识度为代价
- 构图：角色充满画面但不碰边，小屏幕下情绪明确；无需每张写字
- 描述：用短句记录实际画面及表达意图，避免虚构图中没有的内容

`art/character-sheet.png` 是高分辨率视觉参考，不受 192 像素上限限制

## 新增素材

优先补充缺少的情绪，再尝试日常场景。可以增加新道具，但避免随意改变灰斑位置、线条和整体性格。第三方角色、流行表情包临摹、明显商标或不可确认授权素材不进入官方素材库
